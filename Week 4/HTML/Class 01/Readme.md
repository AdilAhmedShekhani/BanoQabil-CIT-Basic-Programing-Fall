# HTML Class 1 — Introduction to HTML

## What We Learned

In this class, we started learning HTML and created our first simple web page.

### 1. What Is HTML?

HTML stands for **HyperText Markup Language**. It is used to create the structure of a web page. HTML helps us add headings, paragraphs, images, links, and other content to a website.

### 2. HTML Tags

HTML tags tell the browser what type of content we want to display.

Examples:
- `<h1>` is used for a main heading.
- `<p>` is used for a paragraph.

Most HTML elements have an opening tag and a closing tag.

Example:

```html
<p>This is my first paragraph.</p>
```

### 3. HTML Attributes

Attributes provide extra information about an HTML element. They are usually written inside the opening tag.

Example:

```html
<p title="About me">I am learning HTML.</p>
```

Here, `title` is an attribute.

### 4. Installing Visual Studio Code

We learned how to install **Visual Studio Code (VS Code)**. It is a code editor that helps us write and manage HTML files.

### 5. Creating the HTML Boilerplate

In VS Code, we can type `!` and press **Enter** or **Tab** (depending on the editor settings) to generate the basic HTML structure.

Example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Page</title>
</head>
<body>

</body>
</html>
```

We discussed the main parts:

- `<!DOCTYPE html>` tells the browser that the document uses HTML5.
- `<html>` contains the HTML for the page.
- `<head>` contains information about the page.
- `<meta charset="UTF-8">` helps display different characters correctly.
- The viewport meta tag helps the page fit different screen sizes.
- `<title>` sets the title shown in the browser tab.
- `<body>` contains the content displayed on the web page.

### 6. Heading Tags: `<h1>` to `<h6>`

HTML has six heading levels:

- `<h1>` — the main or most important heading
- `<h2>` — a second-level heading
- `<h3>` — a third-level heading
- `<h4>` — a fourth-level heading
- `<h5>` — a fifth-level heading
- `<h6>` — a sixth-level heading

Example:

```html
<h1>Welcome to My Website</h1>
<h2>About Me</h2>
<h3>My Hobbies</h3>
<h4>Reading</h4>
<h5>My Favourite Books</h5>
<h6>More Information</h6>
```

Use headings according to the structure of your content, not only to change the text size.

### 7. Paragraph Tag: `<p>`

The `<p>` tag is used to write a paragraph.

Example:

```html
<p>Hello! My name is Ali. I am learning HTML and want to create websites.</p>
```
