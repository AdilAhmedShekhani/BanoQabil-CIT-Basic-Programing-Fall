# AI-Assisted Programming & Digital Skills Course

A practical, beginner-friendly course designed to build **digital literacy, programming fundamentals, problem-solving skills, AI awareness, and real-world project development** using **JavaScript**.

The course starts from the basics of computers and the internet and gradually moves toward **JavaScript programming, APIs, JSON, databases, Git/GitHub, AI-assisted coding, and a final capstone project**.

---

## 🎯 Course Objectives

By the end of this course, students will be able to:

- Understand how computers, operating systems, browsers, websites, DNS, and networks work.
- Use digital productivity tools such as Google Docs, Sheets, and Slides.
- Understand the fundamentals of Artificial Intelligence and Generative AI.
- Understand programming fundamentals using JavaScript.
- Write JavaScript programs using variables, data types, operators, conditions, loops, and functions.
- Work with JavaScript arrays, objects, and other common data structures.
- Handle errors and debug JavaScript programs.
- Work with JSON and external files/data.
- Understand basic algorithms and problem-solving techniques.
- Understand databases and basic SQL concepts.
- Understand APIs and make API requests using JavaScript.
- Use AI tools such as ChatGPT and GitHub Copilot responsibly during development.
- Use Git and GitHub for version control and project management.
- Build, document, and present a complete final project.
- Develop basic portfolio, resume, interview, and professional skills.

# 🤖 AI-Assisted Learning

AI is integrated throughout the course as a **learning and development assistant**, not as a replacement for understanding.

Students will learn how to:

- Ask better technical questions
- Understand AI-generated explanations
- Debug JavaScript errors with AI assistance
- Improve and refactor code
- Generate project ideas
- Understand unfamiliar code
- Verify AI-generated information
- Identify incorrect or unreliable AI output
- Use AI responsibly and ethically
- Write effective prompts for coding tasks

### AI Learning Principle

> **Use AI to learn faster, not to avoid learning.**

Students should be able to explain the logic and functionality of the code they submit.

# 🏆 Final Capstone Project

The final project is the major practical component of the course.

Students will:

1. Select a project idea.
2. Define the project scope.
3. Plan the required features.
4. Design the project structure.
5. Build the application using JavaScript.
6. Work with APIs, JSON, or databases where appropriate.
7. Use AI tools responsibly during development.
8. Test and debug the project.
9. Upload the project to GitHub.
10. Prepare project documentation.
11. Present the completed project.
